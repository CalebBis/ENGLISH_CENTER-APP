## Connexion

### Accès à l'application
1. Lancer l'application
2. Entrer les identifiants
3. Cliquer sur "Connexion"

**Rôles disponibles:**
- **Admin**: Accès complet à toutes les fonctionnalités
- **Secrétaire**: Gestion étudiants, paiements, présence
- **Enseignant**: Voir les classes, enregistrer la présence
- **Étudiant**: Consulter sa progression et ses notes

### Mots de passe oubliés
1. Cliquer sur "Mot de passe oublié?"
2. Entrer l'email
3. Un lien sera envoyé par email
4. Créer un nouveau mot de passe

## Gestion des Étudiants

### Voir la liste des étudiants
1. Menu → Étudiants
2. Vue: liste complète avec filtres

### Chercher un étudiant
1. Entrer le nom, email ou téléphone
2. Cliquer sur "Chercher"
3. Les résultats s'affichent

### Ajouter un nouvel étudiant
1. Cliquer sur le bouton "+" ou "Ajouter un Étudiant"
2. Remplir les champs:
   - Prénom *
   - Nom *
   - Email *
   - Téléphone *
   - Niveau (sélectionner dans la liste)
   - Date de naissance (optionnel)
   - Adresse (optionnel)
   - Infos parent (optionnel)
3. Cliquer sur "Ajouter Étudiant"

### Modifier un étudiant
1. Cliquer sur l'étudiant dans la liste
2. Cliquer sur "Modifier"
3. Changer les informations
4. Cliquer sur "Enregistrer"

### Supprimer un étudiant
1. Cliquer sur l'étudiant
2. Cliquer sur "Supprimer"
3. Confirmer la suppression
*Note: La suppression est définitive*

### Fiche détaillée
Voir:
- Informations personnelles
- Classes inscrites
- Historique de paiement
- Résultats des examens
- Taux de présence

## Gestion des Classes

### Voir les classes
1. Menu → Classes
2. Filtrer par niveau si nécessaire
3. Voir les détails

### Créer une classe
1. Cliquer sur "Ajouter une Classe"
2. Remplir:
   - Nom de la classe *
   - Niveau *
   - Enseignant *
   - Horaire *
   - Lieu *
   - Capacité maximum *
   - Description (optionnel)
3. Cliquer sur "Créer"

### Inscrire un étudiant
1. Ouvrir la classe
2. Cliquer sur "Ajouter un Étudiant"
3. Sélectionner l'étudiant
4. Confirmer

### Voir les inscrits
1. Ouvrir la classe
2. Section "Inscrits": liste complète
3. Cliquer sur un étudiant pour ses détails

### Consulter l'horaire
1. Vue calendrier de la classe
2. Voir les séances programmées
3. Voir les absences

## Gestion des Paiements

### Enregistrer un paiement
1. Menu → Paiements
2. Cliquer sur "Enregistrer un Paiement"
3. Sélectionner l'étudiant
4. Entrer:
   - Montant *
   - Date du paiement
   - Méthode (cash, card, transfer)
   - Notes (optionnel)
5. Cliquer sur "Enregistrer"

### Voir les paiements d'un étudiant
1. Aller sur la fiche de l'étudiant
2. Section "Paiements"
3. Historique complet visible

### Voir les impayés
1. Menu → Paiements
2. Cliquer sur "Voir les Impayés"
3. Liste des paiements non réglés
4. Envoyer un rappel si nécessaire

### Générer une facture
1. Sélectionner le paiement
2. Cliquer sur "Générer Facture"
3. Télécharger ou envoyer par email

### Rapports financiers
1. Menu → Rapports
2. Sélectionner "Revenus Mensuels"
3. Voir les revenus par période
4. Exporter en PDF/Excel

## Présence et Progression

### Enregistrer la présence
1. Menu → Présence
2. Sélectionner la classe et la date
3. Marquer chaque étudiant:
   - ✅ Présent
   - ❌ Absent
   - ⚠️ Justifié
4. Ajouter notes si nécessaire
5. Enregistrer

### Voir les statistiques de présence
1. Menu → Présence
2. Voir le taux par classe
3. Voir les absences par étudiant

### Enregistrer les notes aux examens
1. Menu → Examens
2. Sélectionner l'examen
3. Entrer les notes pour chaque étudiant (0-100)
4. Ajouter une note écrite si besoin
5. Enregistrer

### Voir la progression
1. Fiche étudiant → Progression
2. Voir:
   - Notes moyennes
   - Taux de présence
   - Recommandation de passage
3. Proposer un passage si conditions remplies (>70% notes + >80% présence)

## Rapports

### Types de rapports disponibles

#### Résumé
- Vue d'ensemble: étudiants, classes, revenus, présence

#### Étudiants Actifs
- Liste complète avec niveaux

- Revenus par mois

- Identifier absentéistes

#### Classes Remplies
- Voir les classes pleines
- Ouvrir nouvelles classes si besoin

#### Impayés
- Liste des retards de paiement
- Contact parent/étudiant

### Exporter les rapports
1. Sélectionner le rapport
2. Cliquer sur "PDF" ou "Excel"
3. Télécharger le fichier
4. Ou envoyer par email directement

## FAQ

### Q: Comment réinitialiser un mot de passe?
A: Cliquer sur "Mot de passe oublié?" sur l'écran de connexion

### Q: Puis-je exporter les données?
A: Oui, via le menu Rapports → Exporter en PDF/Excel

### Q: La présence est-elle synchronisée?
A: Oui, en temps réel dans la base de données locale

### Q: Puis-je enregistrer la présence offline?
A: Oui, les données sont sauvegardées localement et synchronisées

### Q: Comment générer un certificat?
A: Fiche étudiant → Générer Certificat (après passage de niveau)

### Q: Comment ajouter un enseignant?
A: Menu → Enseignants → Ajouter Enseignant

### Q: Quelle est la capacité maximum des classes?
A: À définir lors de la création (pas de limite)

### Q: Puis-je modifier une classe après création?
A: Oui, via Menu → Classes → Modifier

### Q: Comment sauvegarder mes données?
A: Menu → Paramètres → Sauvegarder

### Q: Comment restaurer une sauvegarde?
A: Menu → Paramètres → Restaurer
